The Bitzkey brain

One network per animal: 236 senses in, 147 values out. Inborn intellect decides what lies between: first more hidden layers, then wider ones.

Hidden layers: one per point of intellect, at least one, up to four (MAX_DEPTH). Each has 38 neurons (BASE_WIDTH), plus 5 more for each point beyond 4 (WIDTH_STEP), so 53 at intellect 7. Red marks what the current intellect adds over the one below it. Short-term memory is the loop: 16 neurons written each choice and read back as senses on the next. Long-term memory has no neurons of its own: it is the weights themselves, and the mental map of remembered places kept beside the brain and read in as 9 senses.
